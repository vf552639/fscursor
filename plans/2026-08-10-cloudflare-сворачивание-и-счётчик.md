# Cloudflare: сворачивание аккаунтов + счётчик доменов

Источник: `task5.md` (корень репозитория).

## Контекст

На вкладке Cloudflare карточка аккаунта всегда развёрнута целиком (строка токена
+ блок зон). При десятках аккаунтов страница становится неуправляемо длинной.
Нужны две правки, обе — в `frontend/src/pages/Cloudflare.tsx`:

1. **Сворачивание аккаунта** — клик по шеврону/имени скрывает строку токена и
   блок зон, шапка остаётся. По умолчанию развёрнуто.
2. **Счётчик доменов** — рядом с именем аккаунта число доменов **в приложении**
   с этим `cloudflare_account_id` (не путать с `Zones (N)` — это живые зоны CF).

Автопривязка доменов к Cloudflare по имени зоны в объём **не входит** (разобрано
в `task5.md`, изменений не требует).
